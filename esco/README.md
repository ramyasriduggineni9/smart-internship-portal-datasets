# ESCO Dataset

This folder contains the ESCO (European Skills, Competences, Qualifications and Occupations) dataset.

## Purpose

This dataset is used in the Smart Internship Portal for:

- Student skill mapping
- Skill-gap analysis
- Occupation recommendations
- Internship and career recommendations
- Identifying skills required for different job roles

## Source

[Tabiya Open Dataset – ESCO](https://github.com/tabiya-tech/tabiya-open-dataset)

## Dataset Format

The dataset is provided in CSV format.

The CSV files are stored in the `csv/` folder.

## Usage

The Smart Internship Portal can use this dataset to compare student skills with occupation requirements and identify missing skills.
