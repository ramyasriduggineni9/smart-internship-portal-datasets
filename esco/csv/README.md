# ESCO CSV Files

This folder contains the CSV files used by the Smart Internship Portal.

## Files

1. `skills.csv` – Skills information.
2. `skill_groups.csv` – Groups of related skills.
3. `occupations.csv` – Occupation information.
4. `occupation_to_skill_relations.csv` – Skills associated with occupations.
5. `skill_to_skill_relations.csv` – Relationships between skills.
6. `skill_hierarchy.csv` – Skill hierarchy.
7. `occupation_hierarchy.csv` – Occupation hierarchy.
8. `isco_groups.csv` – ISCO occupation groups.

## Source

https://github.com/tabiya-tech/tabiya-open-dataset

## Application

These files support skill mapping, skill-gap analysis and career recommendations in the Smart Internship Portal.
