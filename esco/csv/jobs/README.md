# Job Postings Dataset

This folder contains job-posting data for the Smart Internship Portal.

## Purpose

- Job recommendations based on student skills
- Internship and job-role matching
- Career exploration
- Analysis of required skills and qualifications

## Dataset Source

[Kaggle – Jobs on Naukri.com](https://www.kaggle.com/datasets/PromptCloudHQ/jobs-on-naukricom)

## Note

This dataset contains sample/historical job postings. It is not a live job feed. Check the dataset's licence before redistributing it.
